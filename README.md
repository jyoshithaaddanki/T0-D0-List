# ✅ To-Do List

## 📌 Project Description

To-Do List is a simple web application that helps users manage their daily tasks. Users can add tasks, mark tasks as completed, and delete tasks when they are no longer needed.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and clean interface
* Responsive design
* Easy to use

## ▶️ How to Run

1. Create a folder named `To-Do-List`.
2. Create these files:

```text
To-Do-List/
│
├── index.html
├── style.css
└── script.js
```

3. Add the HTML, CSS, and JavaScript code to the respective files.
4. Open `index.html` in your browser.
5. Start adding your tasks.

## 📊 Example

```text
        MY TO-DO LIST

[ Enter your task... ] [ Add ]

☐ Complete assignment       [Delete]
☑ Study JavaScript          [Delete]
☐ Submit project            [Delete]
```
